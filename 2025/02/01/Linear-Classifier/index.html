Linear Classifier

algebraic viewpoint

代数公式：

  • f(x,W) = Wx + b
  • f(x,W) = [W,b] * [x;1]

visual viewpoint

将权重W的行向量卷为像素的形式，每行权重理解为一个识别的模式，与原图像点积。当原图像向量与权重向量同向时，点积的结果才会最大，代表原图像与权重只相差一个系数。

geomatric viewpoint

每个超平面将高维空间各自分割为两部分。一部分区域是该超平面代表的对象，另一部分区域不是 超平面表示的对象

Loss Function

抽象形式：$L = \frac{1}{N}\sum_{i}L_i(f(x_i, W), y_i)$

Multiclass SVM Loss

训练数据 i 的损失函数：Li = ∑j ≠ yimax(0,sj−syi+1)

其中 j 遍历所有的label，yi为correct label。

Li计算所有其它label得分与correct label得分的差，加上偏移量1后与0取最大值。

直观上理解，当其它label得分均比correct label低至少1分时，损失函数值才为0。应该是为了拉开错误答案和正确答案之间得分的差距

Cross-Entrophy

训练数据 i 的损失函数：$L_i = -log(\frac{e^{s_k}} {\sum_{j} e^{s_j}})$

其中softmax函数 $P(Y=k|X=x_i)=\frac{e^{s_k}}{\sum_{j}e^{s_j}}$完成了score的非标准概率化（变为正数）和标准化（映射到[0, 1]）两个过程。

交叉熵损失仅对正确label的概率值取负对数。直观上理解，当概率值接近1，交叉熵损失接近0，模型训练得好；反之则交叉熵损失接近正无穷。

取负对数是极大似然估计的结果，需要更进一步的数学理解

Regularization

$L = \frac{1}{N}\sum_{i}L_i(f(x_i, W), y_i) + \lambda R(W)$​

一些简单例子：

  • R(W) = ∑k∑lWk, l2
  • R(W) = ∑k∑l|Wk, l|
  • R(W) = ∑k∑lβWk, l2 + |Wk, l|

purpose：

  • 可以在模型中添加“最小化训练误差”无法加入的人为偏好
  • 避免过拟合
  • 增加曲率，有利于采用梯度下降优化

express preference

如果两个权重在计算得分时结果相同，可以用正则化对其进行选择

prefer simpler models

防止过拟合，避免产生复杂模型
