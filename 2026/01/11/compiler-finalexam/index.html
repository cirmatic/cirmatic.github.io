BUAA编译实验期末2026

编译实验期末包括四个要提交的题：

  • 文法修改题（10分）：在原本文法上新增内容，需要修改编译器代码后提交
  • 竞速排序题（10分）：没有修改文法，生成mips的可以直接交。之前没有参与竞速排序的不用交
  • 优化前/后代码：对竞速排序题公开的样例，提交优化前/后的中间/目标代码
  • 简答题（5分）：根据生成的代码（pcode/llvm、mips）选择一道简答题回答并提交

文法修改题

这道题修改了两处文法：

  1. Stmt → LVal ‘=’ Exp ‘;’ | ‘cin’ ‘>>’ LVal ‘;’

    其中cin的 token 是CINTK，>>的 token 是SHF。这个新文法需要进行错误处理，包括h：不改变常量的值和i：缺少分号。新增的cin效果和getint一样，都是从标准输入读入一个数字，被读入的数存取LVal中。

  2. MulExp → UnaryExp | MulExp (’*’ | ‘/’ | ‘%’ | ‘->’) UnaryExp

    其中->的 token 是 LEFTQRIGHTTK（好像是，记不清了）。运算含义是：a->b = a + (a + 1) + (a + 2) + ... + b。运算的优先级和*、/、%相同。

简答题

考试的简答题似乎并没有想象中的那么签到，还是需要预留一些时间进行作答的（其实是我对代码太不熟悉了）

简答题要求结合自己的代码回答问题，需要具体到某个文件、类、函数、代码行之类的

mips的简答题是根据竞速排序的那段公开样例，回答四个小问，大概是这样：

  1. main函数调用rnd函数时传入了5个参数。根据MIPS调用规范，前四个参数存在$a0-$a3，你的编译器是如何处理第五个参数的？rnd函数如何获取第五个参数
  2. partition函数在循环中调用了swap函数。你的编译器是否会在函数调用前保护临时寄存器$t0-$t9？如果swap函数使用了临时寄存器，那么这些寄存器内的值会被覆盖，你是如何解决以上寄存器冲突的？
  3. partition函数的一个参数int a[]向函数传递了一个指针，函数内通过a和临时变量j访问了a[j]。你的mips序列是如何利用a和j访问到物理地址a[j]的？
  4. 对于partition和sort函数，你的编译器实现了什么优化？如果没有实现优化，请考虑一下可以实现什么优化。
